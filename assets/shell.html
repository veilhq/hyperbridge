Settings

Where discovery pulls from, which sources you follow, and how your library moves between machines.

Discovery sources

Choose where the discovery feed may pull images from. Everything is off until you switch it on.

Followed sources

Paste an Are.na channel or user link, a public Pinterest board or section link, or a Tumblr blog such as searchsystem.co. The feed pulls from these on every refresh.

Tags

Rename, merge or delete tags. A change applies to every entry that carries the tag and reaches your other machines on the next sync. Renaming a tag to the name of another tag merges them.

Library

Move your library to another machine. Importing and fetching only add: entries you already have are skipped.

Sync with your other machines Pair two machines once, then one click sends and fetches new entries both ways. Both must be open on the same network. Traffic is not encrypted, so use a network you trust.
Phone capture Let a phone on the same network add links from its share menu. The token can only add links. Traffic is not encrypted, so use a network you trust.
Export to a file Images, tags, sets and followed sources in one zip.
Import from a file Merge a zip exported from another machine.
Share on your network Open a five-minute share so another machine can fetch your new entries. Traffic is not encrypted, so use a network you trust.
Fetch from another machine Enter the address and code shown there.
